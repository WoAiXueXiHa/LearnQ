# 五题与反馈冻结样例

这些文章为本仓库原创的虚构协议说明，可提交；不使用用户原文或真实产品行为作为未经核查的标签。

`cases.jsonl` 每条独立检查一个问题及典型作答。`development` 用于开发，`acceptance` 在本次实现冻结后用于最终检查，不能因为失败修改标签。文章五题的覆盖质量另需人工按整篇主线检查，逐条反馈样例不能替代五题生成验收。

运行 `python3 scripts/prepare-practice-eval.py` 校验文件哈希、原文证据与样例分组，并生成待执行的逐例检查表。准备成功只表示输入契约通过，不表示模型调用、质量或人工验收通过。所有人工结论初始为 `null`。

记录每例模型/提示词/文章索引版本、调用次数、token、耗时、估算费用及账单差异。核对题目覆盖、反馈误判、引用是否支持结论、双来源/版本和不确定性；结果可为通过、失败、无法判定，并写具体原因。

仍需补充：含图中独有知识的文章、自有流程图及关键节点/箭头人工标签、真实官方来源快照；已有 Redis 冻结样例继续使用私有原文及既有哈希，不用这些合成文章替代。真实能力实验仍受零预算限制。本组文章中的攻击文字只用于检查资料与指令的边界，Fake 返回成功不证明真实模型抵抗注入。
